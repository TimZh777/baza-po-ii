Программа: четыре занятия

  1. 1

    Урок 1, 90 минут

    Что такое ИИ и как начать работу

    • Что умеет ИИ и где он ошибается
    • Как мы пришли от чат-ботов к агентам
    • Карта инструментов курса
    • Регистрируем Gmail, ChatGPT, Claude и GitHub
    • Устанавливаем VS Code и Git
    • Разбираем, какие подписки нужны

    После урока все сервисы открыты, рабочие программы установлены и запускаются.

  2. 2

    Урок 2, 90 минут

    Рабочее место с ИИ-агентами

    • Токены, контекст и режимы моделей простыми словами
    • VS Code: окно, папки, настройки, терминал
    • Codex и Claude Code в рабочей папке
    • Git: сохраняем версии проекта
    • Первый приватный репозиторий на GitHub
    • Единый порядок работы с агентом

    После урока вы открываете папку, запускаете агента, видите его правки и находите проект на GitHub.

  3. 3

    Урок 3, 90 минут

    Промпты и вайбкодинг

    • Формула промпта: роль, задача, контекст, формат, ограничения, пример
    • Уточнения, итерации и проверка ответа
    • Работа с файлами и таблицами
    • Пять этапов цифрового продукта
    • Вайбкодинг: страница без знания кода
    • Ваша HTML-страница на GitHub

    После урока вы даёте агенту задачу, проверяете файлы и видите готовую страницу в браузере.

  4. 4

    Урок 4, 90 минут, из них 20 минут на ваши вопросы

    Свой персональный агент

    • Правила для агента: CLAUDE.md и AGENTS.md
    • Профиль, цели, проекты и память
    • Навыки (skills) и плагины
    • Разрешения и безопасность
    • Сборка агента по нашему шаблону
    • Три проверочных задания агенту

    После урока агент знает вашу роль, не выдумывает факты, задаёт уточняющие вопросы и спрашивает разрешения перед рискованным действием.

Частые вопросы

Нужно ли уметь программировать?

Нет. Курс сделан для людей без технической подготовки. Код пишет агент, а вы учитесь ставить ему задачу и проверять результат.

Что нужно для занятий?

Компьютер или ноутбук на Windows или macOS и стабильный интернет. Телефона недостаточно: мы работаем в программе VS Code.

Нужны ли платные подписки?

Да. Агенты Codex и Claude Code работают по платной подписке ChatGPT и Claude. Подписки оплачиваются напрямую сервисам и не входят в стоимость курса. На первом занятии разбираем, какой тариф выбрать; актуальные цены — на сайтах сервисов.

Из какой страны можно учиться?

Из любой, где ChatGPT, Claude и GitHub работают официально и подписку можно оплатить обычной банковской картой. Обход региональных ограничений на курсе не разбираем.

Что если у меня что-то не получится?

После каждого занятия в Telegram приходит инструкция со скриншотами, словарик и чек-лист. Если застряли на каком-то шаге, напишите в чат поддержки его номер, и мы поможем.

Что дальше после курса?

Продвинутый курс: агент на своём сервере круглосуточно, свой Telegram-бот, автоматизация задач бизнеса, сайты и приложения.
